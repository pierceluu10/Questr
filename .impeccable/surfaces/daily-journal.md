# Daily journal

Mode: Persuade on landing, Operate in the app. User delegated direction and direct implementation.

THESIS: Small, doable adventures belong in a daily field journal, with progress that feels encouraging and concrete.
OWN-WORLD: Warm cream, forest green, clay and honey category accents. Georgia display type with a clean system sans for tasks and forms. Flat ruled surfaces, generous margins and a botanical seal built in SVG.
STORY: Understand the three quest categories; start an account; complete a daily quest; reflect; revisit progress and achievements.
FIRST VIEWPORT: Conversational left headline and action beside an explicitly illustrative daily quest journal. Main app: task rows on the left, progress in a narrow rail.
FORM: Grounded candidate 3, seed cb6cede9: field journal. Alternatives: trail map, habit calendar, field journal, adventure passport, progress garden, quest board, daily briefing. Foreign financial and terminal systems lose warmth; retain their legibility.
INTERACTION: Existing Flask actions, authentication and CSRF forms remain intact. Real persisted progress drives screens. Theme control offers accessible light and dark appearances. Charts use one implementation and visible failure/empty states.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
